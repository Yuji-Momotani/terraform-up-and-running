# Terraform Up & Running 学習ワークスペース

『詳解 Terraform 第3版』の第2〜6章、第8〜10章を、AWS上でのハンズオンを通じて学ぶためのワークスペースです。

## 学習方針

- 受講生がコードとコマンドを自分で入力する
- `terraform apply` の前に、必ず `terraform plan` の差分を説明する
- エラーでは、メッセージ、原因、修正、再発防止を記録する
- 認証情報やシークレットをTerraformコードとGitへ保存しない
- 各ハンズオンの最後に、不要な課金リソースを削除する
- 章末問題の結果と次回の開始点を `LEARNING_PROGRESS.md` に残す

## 対象章

- `chapter-02`: Terraformをはじめよう
- `chapter-03`: Terraformステートを管理する
- `chapter-04`: Terraformモジュールで再利用可能なインフラを作る
- `chapter-05`: Terraformのヒントとコツ
- `chapter-06`: Terraformでシークレットを管理する
- `chapter-08`: 本番レベルのTerraformコード
- `chapter-09`: Terraformのコードをテストする
- `chapter-10`: チームでTerraformを使う

## タスクを分けて再開する方法

新しいタスクでは、最初に次のように依頼します。

> `LEARNING_PROGRESS.md` を読み、Terraform講座の第N章を前回の続きから進めてください。
